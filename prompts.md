\# BSRC GenAI Internship - Week 2 Project 3

\# Resume Builder



\## Prompt 1: Create the Project

Create a simple Resume Builder web application using HTML, CSS, and JavaScript. Include a form, live A4 resume preview, three templates, rearrangeable sections, PDF export, save/load resume data, and offline functionality.



\## Prompt 2: HTML Structure

Create the HTML structure for the Resume Builder, including the form, resume preview, template selection, section arrangement, PDF export, and save/load options.



\## Prompt 3: CSS Design

Design the Resume Builder using CSS. Make it clean, professional, responsive, and suitable for an A4 resume.



\## Prompt 4: JavaScript Functionality

Add live preview, three resume templates, drag-and-drop section rearrangement, PDF export, saving resume data as JSON, and loading saved JSON data.



\## Prompt 5: Testing

Test the Resume Builder features and verify that it works offline.
